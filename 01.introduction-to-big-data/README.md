# Module 1: Linux foundations

Run `bash 01.introduction-to-big-data/linux-lab.sh` from the repository root in
WSL or Onyxia. The exercise checks `mkdir`, `ls`, `cat`/file output, `head`,
`tail`, `cp`, `mv`, and `grep` in an isolated temporary directory. For the
interactive `tail -f` and Kubernetes log exercises, follow the
[upstream lab](https://github.com/adaltas/ece-bigdata-2026-fall/blob/main/01.introduction-to-big-data/lab.md).
